> Việc còn mở: [`../../core/handover-roadmap.md`](../../core/handover-roadmap.md) §5.  
> File `_audit-*` / `_plan-*` là bằng chứng một lần rà. Quyết định lát nằm ở file đánh số cạnh module (`18-…`, `20a-…`, `25-…`). Khi hai bên lệch, SSOT thắng.

Ví dụ đã thu hồi: `_audit-golive-doors-2026-09-28.md` dòng VST-02 từng ghi «1–5 mọi hành động». Domain §2.1 là tuân thủ ≤2 chỉ định, bỏ sót ≤1. Không làm theo câu soft đó.
